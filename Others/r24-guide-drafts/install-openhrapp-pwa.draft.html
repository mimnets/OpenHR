OpenHRApp installs to your phone, tablet or desktop from the browser — no app store, no download, no account beyond the one you already have. Once installed it opens like any other app, which matters most for clocking in: fewer taps between arriving and being recorded.

What "installing" actually means

OpenHRApp is a progressive web app. Installing adds it to your home screen or app list and runs it in its own window without browser tabs or an address bar. It is the same application you use in the browser, sharing the same account and the same data — not a separate copy.

It takes a few seconds, needs no permissions of its own, and can be removed like any app.

Android — Chrome

  1. Open OpenHRApp in Chrome and sign in.
  2. Tap the three-dot menu.
  3. Choose Install app or Add to Home screen.
  4. Confirm.

Chrome often offers an install banner on its own after a visit or two. Either route produces the same result.

iPhone and iPad — Safari

It must be Safari. Chrome and Firefox on iOS cannot install web apps — the option simply is not there, which is the usual reason someone reports missing instructions.

  1. Open OpenHRApp in Safari and sign in.
  2. Tap the Share button — the square with an arrow.
  3. Scroll down and choose Add to Home Screen.
  4. Name it and confirm.

Desktop — Chrome or Edge

  1. Open OpenHRApp and sign in.
  2. Look for the install icon in the address bar, usually a small screen with a downward arrow.
  3. Click it and confirm.

If the icon is absent, the menu has Install OpenHRApp or Apps → Install this site as an app.

Why install it?

  • Faster clock-in — one tap from the home screen instead of opening a browser and finding a tab.
  • Full screen — no address bar, so more of the screen is the app.
  • A place for notifications — an installed app can deliver notifications where a tab cannot.
  • Faster loading — the app caches itself, so it starts quickly and tolerates a poor connection better.

Permissions after installing on iPhone

This is the one thing worth knowing in advance. An installed app on iOS asks for camera and location permission separately from Safari. Granting them in the browser does not carry across.

So if clocking in worked in Safari and the camera does not start in the installed app, nothing is broken — grant the permissions again when prompted. If you dismissed the prompt, re-enable them in Settings → OpenHRApp on the device.

Do this before your first shift rather than at the door.

Does it work offline?

Partly, and it is worth being precise about the limits. The app itself loads without a connection, so it opens rather than showing a browser error.

Recording attendance still needs one. Do not assume a punch made with no signal has been saved — if you clock in somewhere with no coverage, check your attendance history once you are back online. A punch that never reached the server is not visible in the app, and the safest habit in a low-signal workplace is to confirm rather than trust.

Keeping it up to date

Updates arrive automatically — there is no store, and nothing to approve. Closing and reopening the app picks up the newest version, which is worth doing if something looks wrong after a release.

Common questions

There is no install option

  • On iPhone or iPad, you must use Safari.
  • It may already be installed — check your home screen or app list.
  • Some managed work devices block installing web apps; your IT team would know.

Do I need to install it?

No. Everything works in the browser. Installing is a convenience, and it matters most for people clocking in daily on a phone.

Will it use much space?

Very little — a few megabytes. There is no large download.

Can I install it on more than one device?

Yes, on as many as you like. Note that display preferences such as light or dark mode are stored per device, so you set those once on each.

How do I remove it?

Delete it like any app. Your account and data are unaffected — sign in through the browser and everything is there.
